# Forestín Play V3.0 — Memorice Mobile integrado

## Alcance
Esta versión integra el nuevo pool gráfico aprobado en el Memorice, manteniendo React + Vite + Node/Express.

### Memorice V3
- 15 diseños de frente aprobados + 1 reverso.
- Selección aleatoria según dificultad:
  - Fácil: 6 parejas / 90 s
  - Medio: 8 parejas / 75 s
  - Difícil: 10 parejas / 60 s
- Tiempo y movimientos dinámicos.
- Barra de avance 🔥 → 🌳.
- Forestín entrega tips al encontrar parejas.
- Botón Volver siempre disponible.
- Fondo mobile elegido aleatoriamente desde el pool disponible.
- Diseño responsive/mobile-first.

## Ejecutar
```bash
npm install
npm run install:all
npm run dev
```
Abrir http://localhost:5173

## Nota
Los demás cinco juegos permanecen accesibles desde el Home, pero esta entrega concentra la integración visual nueva en Memorice.
